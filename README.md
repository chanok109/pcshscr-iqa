# pcshscr-iqa

ระบบประกันคุณภาพภายในสถานศึกษา (Internal Quality Assurance) — โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย เชียงราย

## เอกสาร
- [การออกแบบโครงสร้างระบบประกันคุณภาพภายใน](docs/iqa-system-design.md) — โครงสร้างองค์กร, มาตรฐานและตัวชี้วัด, กระบวนการ 6 ขั้นตอน (PDCA), ปฏิทินงาน, ระบบหลักฐาน และสถาปัตยกรรมระบบดิจิทัล

## เว็บไซต์ระบบ IQA (`site/`)
เว็บไซต์ต้นแบบแบบ static (HTML/CSS/JavaScript ไม่ต้อง build) ประกอบด้วย
- **หน้าแรก** — สรุปจำนวนมาตรฐาน หลักฐาน และระดับคุณภาพรายมาตรฐาน
- **โครงสร้าง** — แผนภูมิองค์กรประกันคุณภาพและบทบาทหน้าที่
- **มาตรฐาน** — มาตรฐาน 1–4 ประเด็นพิจารณา ตัวชี้วัด ค่าเป้าหมาย และเกณฑ์ 5 ระดับ
- **กระบวนการ** — 6 ขั้นตอนตามกฎกระทรวง 2561 (PDCA) และปฏิทินงานรายปี
- **คลังหลักฐาน** — บันทึกหลักฐาน (สร้างรหัสอัตโนมัติ เช่น `2569-1.1.3-D-001`), ค้นหา/กรอง, ตรวจความครบถ้วน P-D-C-A รายประเด็น, ส่งออก CSV/JSON และนำเข้า JSON
- **ผลการประเมิน** — กรอกผลการดำเนินงาน ระบบเสนอระดับเบื้องต้น ให้คณะกรรมการตัดสินระดับสุดท้าย พร้อมบันทึกจุดเด่น/จุดที่ควรพัฒนา
- **รายงาน** — ร่าง SAR สร้างจากข้อมูลข้างต้น พิมพ์หรือบันทึกเป็น PDF ได้

### เปิดใช้งาน
```bash
cd site && python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```
หรือนำโฟลเดอร์ `site/` ไปวางบน GitHub Pages / เว็บเซิร์ฟเวอร์ของโรงเรียนได้ทันที

### ระบบหลังบ้าน (เมนู "หลังบ้าน" — เฉพาะผู้ดูแลระบบ)
- **ปีการศึกษา:** เพิ่มปีใหม่โดยคัดลอกค่าตั้งค่าจากปีก่อน (เลือกใช้ผลการประเมินของปีก่อนเป็น "ผลปีก่อน" ได้) ตั้งปีปัจจุบัน ลบปี ผู้ใช้เลือกดูปีอื่นได้จากตัวเลือกปีการศึกษาที่แถบด้านบน
- **เป้าหมาย และ กลยุทธ์:** แก้ไข เพิ่ม ลบ จัดลำดับ และเชื่อมกลยุทธ์กับเป้าหมาย/มาตรฐาน
- **มาตรฐาน ตัวชี้วัด ค่าเป้าหมาย:** ประเด็นพิจารณา ตัวชี้วัด ค่าเป้าหมาย หน่วย ทิศทาง (ไม่น้อยกว่า/ไม่เกิน) ผลปีก่อน รายการตรวจสอบ rubric วิธีตัดสินและเกณฑ์ระดับคุณภาพ
- แก้ไขบนฉบับร่าง ระบบตรวจความถูกต้องก่อนบันทึก และส่งออก/นำเข้าค่าตั้งค่าเป็น JSON ได้
- ผลการประเมินแยกตามปีการศึกษา และผูกกับ id ของตัวชี้วัด จึงจัดเรียงตัวชี้วัดใหม่ได้โดยผลไม่เลื่อน

### ปรับแก้ข้อมูล
- ค่าตั้งต้นของปีการศึกษา 2569 (เป้าหมาย กลยุทธ์ มาตรฐาน) ข้อมูลโรงเรียน ปฏิทิน และบทบาทหน้าที่ อยู่ใน `site/assets/js/data.js` เมื่อบันทึกจากหน้าหลังบ้านแล้ว ค่าที่บันทึกจะใช้แทนค่าตั้งต้น
- มาตรฐาน ตัวชี้วัด ค่าเป้าหมาย และเกณฑ์ระดับคุณภาพปีการศึกษา 2569 ตาม **ประกาศโรงเรียน ลงวันที่ 16 พฤษภาคม 2569** (4 มาตรฐาน 33 ประเด็น) ผลปี 2568 จาก **SAR ปีการศึกษา 2568** ใช้เป็นค่าอ้างอิง
- วิธีตัดสินระดับ: มาตรฐานที่ 1, 3 ใช้ค่าร้อยละ (90/80/70/60) · มาตรฐานที่ 2 ใช้จำนวนข้อที่ปฏิบัติได้และ rubric แล้วรวมคะแนน · มาตรฐานที่ 4 ใช้ร้อยละความสำเร็จเทียบค่าเป้าหมาย

### เชื่อม Google Sheets และล็อกอินด้วยบัญชีโรงเรียน
- **ยังไม่ตั้งค่า** (`site/assets/js/config.js` ว่าง) → เว็บไซต์ทำงานใน "โหมดทดลอง" เก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น
- **ตั้งค่าแล้ว** → ครูล็อกอินด้วยบัญชี Google `@pcccr.ac.th` ข้อมูลทั้งหมดบันทึกลง Google Sheet ของโรงเรียน แยกสิทธิ์ตามบทบาท (admin / evaluator / teacher / viewer)
- โค้ดฝั่งเซิร์ฟเวอร์และขั้นตอนติดตั้งทีละขั้น: [`apps-script/README.md`](apps-script/README.md)
